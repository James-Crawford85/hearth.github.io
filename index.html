A place for every adventure.

The table is yours

Built around the game night

Everything a Game Master needs to run a session, and everything players need to join one, in one place that runs on your own machine.

⚔

Run your sessions

Scenes, a combat tracker with initiative and turns, and dice rolled on the server so nobody can fudge them. Chat with whispers and secret GM rolls. A journal for notes and handouts, shared with everyone, some players or no one.

♟

Maps that play

Tokens, walls and doors (locked or secret), line of sight and fog of war, lights and a day-to-night fade, drawings, a ruler and pings. Line a map up with the grid by dragging across a few of its squares.

🛡

Characters that keep up

Sheets that work out the numbers for you, guided character creation, and a level-up dialog that asks for each choice and can take a level back. Forge magic items, and let bonuses and conditions apply themselves.

❖

Your whole library at hand

Monsters, items, spells and rules in searchable collections. Filter by type or book, search the text as well as the names, and, where a system lists requirements, see only what a character qualifies for. The GM can switch whole books off for a campaign.

♫

Set the mood

Playlists that play in sync for everyone, even late arrivals. Ambient sounds placed on the map grow louder as tokens approach and are muffled by walls. Every player sets their own volume.

✦

Yours to keep

Worlds are plain files you can back up, copy or move, with automatic backups on every launch. Host from your PC or an always-on server. Free and open source under the MIT license.

Any system, your rules

Make it your game

Hearth doesn't come locked to one game. Game systems are packages anyone can make and share, and you can build one inside Hearth without writing code.

Build a system

Design stats, resources, skills and item types in the system builder, connect them with formulas, and watch sheets update as you go. Start blank or from a copy of another system.

Let the rules do the work

Lookup tables, resources that refill on a rest, attacks with advantage and critical hits, classes that grant features level by level, and requirements the sheet checks for you.

Share it

Systems, add-on modules and themes are plain folders or zip files. Install one from a link or a file, no store needed. A small example system comes built in.

Get Hearth

Download Hearth

The desktop app hosts your games and joins other people's. It checks for updates by itself.

Windows

Installer (.exe) or the .msi package

macOS

Apple silicon (.dmg) or Intel (.dmg)

Linux

AppImage .deb .rpm

The installers aren't code-signed yet, so your computer may warn you the first time. On Windows choose More info → Run anyway; on macOS, right-click the app and choose Open. Want an always-on server instead? The standalone server builds run on a PC, home server or VPS.

Launch a world

Create a world, pick its game system and press Launch. Hearth starts hosting it and opens it for you as the Game Master.

Invite your players

Add your players with a temporary password, and give them the address the launcher shows. Across the internet, forward the port on your router.

Play

Players join from any web browser, with nothing to install, or from the Hearth app. Everyone sees the table update in real time.
